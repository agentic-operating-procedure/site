The normative specification

Clause families with stable identifiers, machine-readable schemas, and a reference validator. Normative text uses RFC 2119 key words; conformance is clause-by-clause.

Clause families

The schemas

Three machine-readable schemas, validated by the reference implementation in Python and by this site's JavaScript port (parity-verified against the fixture set).

Conformance tiers

Every suite is binary: no partial conformance, no waiveable checks. Tiers are named claims over cumulative suite supersets.
